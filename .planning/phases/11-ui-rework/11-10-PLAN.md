## Planning notes

- Spec-less probe fallback skipped (no REQUIREMENTS.md-backed IDs); truths derive from the UI-SPEC copy contract rows for the Config tab.
- Deliberate refinement of one UI-SPEC copy row: the row lists "switching table/raw mode" as a trigger for the discard dialog. Plan 11-12 makes both env modes views over one `envContent` string, so a mode switch loses nothing and there are no edits to discard — prompting there would force users to throw away work just to change views, contradicting D-20's "two toggleable modes". The dialog therefore fires on navigation away only. Flagged for the developer in the planning return.
- Verified during planning: react-router 7.13's `useBlocker`, `createBrowserRouter`, `createRoutesFromElements`, `RouterProvider` and `createMemoryRouter` are all exported from "react-router"; the app currently uses declarative `BrowserRouter`, under which `useBlocker` throws.
