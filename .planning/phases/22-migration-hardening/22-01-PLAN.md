<objective>
Make every docker/compose child process Docktor spawns hygienic and make the migration request paths safe, before the migration correctness work builds on them.

Purpose: ROADMAP Phase 22 SC#5 ("compose commands run by Docktor never see Docktor's own secrets or COMPOSE_* variables; migration request paths that escape the permitted directories are refused with a validation error; a Linux CI job proves the data copy preserves ownership and modes"). The AppError cause change must land before Phase 24 adds error subclasses (ROADMAP note). The MigrationService constructor is converted to a dependencies object here so plans 22-04..22-08 can add ports without touching every test builder again.
Output: `server/src/lib/compose-env.ts`, allowlisted env in ExternalStackControl/DockerExecutor/ComposeRewriter, the `linux-root-migration` CI job, the AppError `options` parameter, hardened shared schemas, realpath check, typed analyzer, `MigrationServiceDependencies`.
</objective>
