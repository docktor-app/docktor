<objective>
Prove the whole release pipeline with a release-candidate tag before anything is pointed at users: CI gate, clean-checkout multi-arch build, GHCR push, both-platform smoke test and exact tag set.

Purpose: no Docker daemon is available on this host, so the Dockerfile and publish workflow (16-04) can only be proven on GitHub Actions. RESEARCH Pitfall 8 and the orchestrator require a v0.1.0-rc.1 dry run before docker-compose.yml is flipped to :latest (16-10). A v* tag push uses the workflow file of the tagged commit, so the dry run runs from the phase branch without touching main. The first push creates the GHCR package (private by default; 16-10 makes it public).

Output: a green Publish run for v0.1.0-rc.N, recorded image digest and tag list, and the maintainer's prerequisite answers. No repository file changes unless a fix-forward is needed.
</objective>
