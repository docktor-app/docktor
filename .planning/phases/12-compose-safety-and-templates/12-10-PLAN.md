**Implements:** [docktor-app/docktor#19](https://github.com/docktor-app/docktor/issues/19) — "users can add additional template repositories" and the user-visible half of "validated on load".

<objective>
Let users manage template sources. Tracer (Task 1): in Settings → Stacks a user pastes a repository URL into the Template Repositories card, clicks "Add Repository", Docktor validates, stores, syncs it and the new row appears with its status. Task 2 completes the card: per-repo sync status, sync errors, the list of rejected templates with reasons, "Sync now", and duplicate/invalid URL handling.

Removing a repository is deliberately not part of this plan (not in #19's acceptance criteria; UI-SPEC marks it as a planning-time addition that would need a type-to-confirm dialog) — see the phase return notes for a follow-up issue suggestion.
Output: repo list/add API, Template Repositories settings card.
</objective>
