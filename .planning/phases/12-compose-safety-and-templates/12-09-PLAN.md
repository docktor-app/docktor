<objective>
Give users the template experience on the client. Tracer (Task 1): from Create Stack → "Start from Template" → card grid → "Use Template" on a single-variant template → the Create form opens prefilled → "Create Stack" (through the normal review flow) → the new stack's page. Task 2 adds the multi-variant dialog, search + category filter, and every UI-SPEC state (first-run skeleton, empty, sync error with Retry), plus the usage-notes display.

The browser lives under `/stacks/create/templates` (not `/stacks/templates`) so it can never collide with a stack whose slug is "templates" — stack ids cannot contain "/".
Output: template API client, hooks, three domain components, browse page, template-aware create page.
</objective>
