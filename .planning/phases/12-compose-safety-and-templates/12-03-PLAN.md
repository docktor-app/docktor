## Planning notes

- RESEARCH Critical Finding / Pitfall 1 is accepted as stated by the orchestrator: inside the Docktor container `ss`/`lsof` only see Docktor's own network namespace. The database and Docker-API tiers are the reliable layers; the socket tier is a documented best-effort last resort (most useful when Docktor runs directly on a host, e.g. `yarn dev`). This plan's code comments say so; plan 12-08's UI copy says so.
- Range expansion is capped (`MAX_PORTS_PER_RANGE = 1024`, `MAX_REQUESTED_PORTS = 4096` per stack) so a hostile `1-65535` range cannot make the check expensive; ports beyond the cap are skipped and the cap is documented in a comment.
