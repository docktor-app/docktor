## Flagged assumptions (spec-less probe)

- **FLAGGED ASSUMPTION — #18, probe row `unclassified` / `unresolved`:** the probe could not classify an edge for #18. The open edge identified during planning is *preview-to-confirm drift*: the diff is computed against the on-disk file at preview time; if the file is changed externally (SSH edit picked up by FileWatcher) between preview and "Confirm & Apply", the confirmed write overwrites that external change without a second review (last-writer-wins — identical to pre-phase behaviour, and FileWatcher's external-change toast still fires). No base-hash check is added in this phase. Surface this to the developer at verify time; a follow-up could send the previewed base hash with the PUT and answer 409 on mismatch.
