**Implements:** [docktor-app/docktor#7](https://github.com/docktor-app/docktor/issues/7), UI half: warnings are surfaced to installs whose owners never read container logs (CONTEXT D-13). Server half: 16-01.

<objective>
Show the boot-time environment warnings from 16-01 as a dismissible banner on every authenticated page.

Purpose: D-13 requires warnings to be logged AND visible in the UI. Banner placement is Claude's discretion as long as it is visible without navigating to Settings: AppLayout (the shell of every authenticated route) is chosen so it appears on the dashboard and on every other page. The report is static per boot, so it is fetched once over REST (no SSE, no polling).

Output: docs-link helper, settings API function, hook with localStorage dismissal, presentational banner, AppLayout wiring, unit tests, the Playwright default stub and one journey spec.
</objective>
