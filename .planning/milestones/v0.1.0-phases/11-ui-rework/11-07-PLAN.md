|-----------|----------|-----------|----------|-------------|-----------------|
| T-11-20 | Tampering | proxy domain/port input | low | mitigate | Client validates with the shared assignDomainSchema (hostname pattern, port range, certSource/certificateId pairing); the server re-validates with the same schema — unchanged trust model |
| T-11-21 | Elevation of Privilege | pre/post backup hook commands | medium | accept | Hooks are shell commands an authenticated admin could already set through the old card; moving the form into a dialog does not widen who can set them or how they execute. Single-admin self-hosted trust model; tracked as existing behaviour, not introduced here |
| T-11-22 | Tampering | edit flow re-assigning an existing domain | low | mitigate | Domain and service are read-only in edit mode, so edit can only update port/TLS/cert on the row it opened from; the server's per-stack lock and upsert rules are unchanged |
| T-11-23 | Tampering (XSS) | domain names / hook commands in lists and summary | low | accept | Rendered as React text; no HTML rendering path |
