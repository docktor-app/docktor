## Planning notes

- Spec-less probe fallback skipped (no REQUIREMENTS.md-backed IDs); truths derive from D-15/D-16 and the UI-SPEC dark-mode-toggle rows.
- This is a client-rendered Vite SPA with no hydration step, so RESEARCH's `suppressHydrationWarning` note does not apply; flash prevention comes from a tiny static pre-paint script in index.html that mirrors next-themes' storage key and class strategy.
- Toggle shape: a DropdownMenu (Light / Dark / System) behind the sun/moon icon button — the shadcn mode-toggle pattern. A two-state button would give users no way back to "follow OS" after overriding, which D-15's system default implies they should have.
- E2E isolation: theme.spec.ts runs in the same wave as plan 11-04, which adds a dashboard-only API request, so it visits `/stacks` and a stack detail page (not `/`) and stubs every request it triggers.
