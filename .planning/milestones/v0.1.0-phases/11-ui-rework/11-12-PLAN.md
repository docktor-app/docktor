## Planning notes

- Spec-less probe fallback skipped (no REQUIREMENTS.md-backed IDs); truths derive from D-06/D-20/D-21/D-22 and the UI-SPEC "Env editor table mode" rows (loading and zero-one-many are dismissed there).
- Pitfall 4 decision (RESEARCH assumption A4): preserve, never strip. A line is a table variable only if it matches `^[A-Za-z_][A-Za-z0-9_]*=` exactly; everything else is a passthrough line kept verbatim in place. This makes `serializeEnvFile(parseEnvFile(s)) === s` hold for every string, so opening table mode can never silently rewrite a hand-annotated file.
- New variables are appended after the last existing line (before a trailing newline, if the file had one).

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| .env content (may contain secrets) → browser UI | server-stored env text is parsed and displayed in the table and raw editor |
| user edits → PUT /api/stacks/:id envContent | the serialized string is sent to the existing endpoint (server Zod validation unchanged) |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-11-36 | Information Disclosure | EnvEditor secret masking | medium | mitigate | Masking hides secret-looking values on screen (shoulder-surfing), never through tooltips; the helper text states plainly it is display-only and the file is plain text, so it is not presented as a security control (RESEARCH Security Domain) |
| T-11-37 | Tampering | table-mode serialization | medium | mitigate | Lossless parse/serialize with a tested round-trip identity; only edited lines change, so opening table mode cannot corrupt or strip comments/unrecognised lines in an existing .env |
| T-11-38 | Tampering (injection into .env) | variable keys | low | mitigate | Keys must match ENV_VARIABLE_KEY_PATTERN before Save enables; a value containing a newline cannot be typed into a single-line input, so a table edit cannot inject extra lines |
| T-11-39 | Tampering (XSS) | rendering env keys/values | low | accept | Values are input values / CodeMirror text, never HTML |
</threat_model>
