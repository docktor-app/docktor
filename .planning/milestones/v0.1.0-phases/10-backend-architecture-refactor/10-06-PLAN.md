<objective>
Complete the layering restructure inside the application layer: every service depends on named ports rather than concrete infrastructure classes (D-07, PD-3), and the pure business rules D-08 names are pulled down into `domain/` where they can be tested without a service, a repository or a mock.

Purpose: `domain/` is currently five files — a state machine and four helpers — while retention-policy math sits inside an 815-line backup service and the proxy idempotency rules sit inside a 452-line proxy service. D-08 asks for the inversion: application services orchestrate domain rules plus repositories, rather than embedding the rules.
Output: two new pure domain modules with their own tests, and five application services whose constructor signatures name only ports and repository read-ports.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client -> application service | Domain and certificate assignment requests carry client-supplied values that the extracted rules now decide on |
| application -> host filesystem | `MigrationService` resolves operator-supplied paths and volume names into real file operations |
| application -> restic repository | The retention policy drives which snapshots are forgotten |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-10-18 | Tampering | `MigrationService` path guards (`VOLUME_NAME_PATTERN`, containment assertion) | high | mitigate | Task 3 forbids moving or relaxing them and asserts their occurrence count is unchanged; the type change is confined to constructor parameter types |
| T-10-19 | Elevation of Privilege | extracted proxy assignment rules | high | mitigate | The refusal paths (port pairing conflict, custom source without a certificate id) move with the same error class and byte-identical message text, asserted in the acceptance criteria. | T-10-20 | Denial of Service | retention policy parsing | medium | mitigate | The silent fall-through to defaults on malformed stored JSON is preserved deliberately (a throwing parse would fail a backup run); the extraction additionally rejects a non-object parse result, closing a latent path to a malformed policy reaching the forget-argument builder |

| T-10-SC | Tampering | npm/pip/cargo installs | low | accept | No package is installed |
