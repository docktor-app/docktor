<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client -> backup settings writes | Restic repository passwords, SFTP keys and S3 secrets are submitted here |
| client -> schedule writes | A client-supplied cron expression creates a runtime cron task |
| application -> restic repository | Backup and restore operations act on operator data |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-10-33 | Information Disclosure | backup credential writes | high | mitigate | The three inline encrypted writes move onto the single encrypted-write path in `SettingsService`, with the blank-value conditionals preserved and asserted per field — a blanked backup password would silently break every subsequent scheduled backup and is the realistic failure here |
| T-10-23 | Denial of Service | client-supplied cron expression | high | mitigate | The validation call moves with the handler and is asserted to appear exactly once, in the service, with the same refusal and message. Persist-then-notify ordering means a rejected or failed persist never reaches the scheduler |
| T-10-34 | Denial of Service | composition-root module cycle | high | mitigate | The scheduler facade's module has only the cron package as a top-level import; the executor confirms this before adding the composition-root import and records the confirmation, because a runtime-only cycle here fails server startup rather than a test |
| T-10-35 | Elevation of Privilege | not-found handling on backup reads | medium | mitigate | The throwing repository lookups stay the mechanism, so an unknown id still raises the typed not-found error rather than falling through to a null that a handler might mishandle; asserted by a test |
| T-10-32 | Elevation of Privilege | auth preHandlers on the backups routes | high | mitigate | No route registration, schema or preHandler is edited; the summary records the unchanged preHandler list |
| T-10-SC | Tampering | npm/pip/cargo installs | low | accept | No package is installed |
</threat_model>
