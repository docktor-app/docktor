**Implements:** [docktor-app/docktor#23](https://github.com/docktor-app/docktor/issues/23). Gap closure for 14-UAT.md gap G-14-2 (test 2, minor, client only). Root cause: `.planning/debug/health-history-row-transition-wraps-g14-2.md`.

<objective>
Fix the two layout defects of the health history row found in UAT test 2: the `healthy → unhealthy` transition wraps when a long message shares its line, and on phones the rows run together.

Purpose: the history panel is how a user reads why a probe-driven service turned unhealthy. A transition squeezed into three lines and rows with no separation make the panel hard to scan, and the Phase 14 jsdom tests could not see either defect because jsdom performs no layout. This plan fixes the markup and adds a browser-measured gate so the regression cannot return unseen.

Output: a restructured `HealthEventRow` (header line plus message line, `divide-y` list, no-wrap transition), jsdom structure tests, two Playwright layout assertions, and the amended row-layout line in 14-UI-SPEC.md.
</objective>
