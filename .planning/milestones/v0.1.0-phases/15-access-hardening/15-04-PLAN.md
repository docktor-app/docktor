<objective>
Close the remaining #46 audit items and give operators the 2FA escape hatch.

Purpose: RESEARCH found that the Fastify routes have no CSRF defence beyond SameSite=Lax, which does not stop a same-site sibling origin (a managed stack's web app on another port of the same host is exactly that), and that the Secure cookie flag silently follows NODE_ENV when BETTER_AUTH_URL is unset, logging out plain-http installs. D-14 asks for tests first and a fix for any gap they reveal; D-15 fixes the Secure derivation; D-09 needs a reset that works without email; D-13/D-16 need operator documentation and a follow-up issue.

Output: a pure Origin guard wired into app.ts, the Secure-cookie derivation, a reset repository/service method plus CLI script, integration tests for CSRF, cookies and reset, corrected security docs, and the password-reset follow-up issue.
</objective>
