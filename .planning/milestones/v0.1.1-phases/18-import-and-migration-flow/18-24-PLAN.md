<objective>
Widen the discovered-stacks card on both import surfaces and let long directories wrap, so the table fits without constant scrolling on desktop while the phone layout stays as it is.

Purpose: `BrownfieldImport`'s Card and the setup step wrapper are capped at `max-w-3xl` (768px). The shadcn `TableCell` is `whitespace-nowrap`, so a long path such as `/host/home/raphael/workspace/docktor/dev-data/docktor/stacks/memos` pushes the table past the card and the table container scrolls horizontally on every scan.
Output: `max-w-6xl` on the card and the wizard wrapper, a wrapping directory cell, a unit test, and Playwright checks at 1280px and 360px.

Out of scope: column changes, pagination, and the migration dialog (its width is MIG-01, already `sm:max-w-5xl`). `components/ui/` is not edited (CLAUDE.md).
</objective>
