<objective>

User decision (G-18-7): same name -> rename the original aside to `<name>-pre-migration` (user-editable, must not exist), build the new stack in the original directory, copy data from the renamed directory; the renamed original is the backup (no extra copy); stopping the old stack is forced; rollback = remove the new directory, rename the original back, restart if stopped. </objective>
