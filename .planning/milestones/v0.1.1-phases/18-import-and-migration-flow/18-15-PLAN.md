**GitHub issues:** [#72 Migration dialog: real diff, explicit backup, stop old stack](https://github.com/docktor-app/docktor/issues/72). Gap closure for UAT gap **G-18-7** (dialog half). The server half (in-place execution, rollback, preview target) is plan 18-12.

<objective>
Adapt the migration dialog to the two cases the user decided for G-18-7:
- Same name, stack already in the stacks folder (in place): the original is renamed aside (user-editable name, must not exist) and kept as the backup, the old stack must be stopped.
- Otherwise: the original stays untouched, so the backup switch defaults to off with a note naming the original path; backup stays an explicit choice.

Purpose: the user sees exactly what happens to the original directory before confirming.
Output: target-aware steps 3 and 4, the aside name in the confirm parameters, the preview request with the stack name, tests and Playwright updates.
</objective>
