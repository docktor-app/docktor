<objective>
Complete the four-step migration dialog of D-12 and send the user's choices to the server. Step 3 is the explicit, default-on, opt-out backup (D-07); step 4 is the explicit, default-on choice to stop the old stack, with a warning when declined (D-10) and a summary of every choice before the single Confirm & Migrate action. `ConfirmMigrateParams` and both API clients carry `backup` and `stopOldStack`, typed by the shared `MigrationExecuteInput` the server validates (plan 18-03). The shell gains the UI-SPEC step indicator, focus management, a stale-preview guard and 44px rows; the parent's toasts describe what happened.

Purpose: the user decides, on one screen they can review, whether a backup is kept and whether the old stack stops, and the server receives exactly those decisions.
Output: four new section components, an updated wizard shell, typed API clients, parent toasts, unit tests and updated Playwright specs.
</objective>
