**GitHub issues:** [#13 Import existing stack](https://github.com/docktor-app/docktor/issues/13). Gap closure for UAT gaps **G-18-3-scan** (UI half: skip reasons always visible with a /host hint) and **G-18-2** (UI half: already-managed rows disabled with an indicator and a link). The server halves are plans 18-09 and 18-11.

<objective>
Show the user why a scan root produced nothing, and stop offering Adopt/Migrate for stacks Docktor already manages.

- G-18-3-scan: today the client shows only "N directories skipped (permission denied)", only when at least one stack was found, and mislabels ENOENT as permission denied. Render every skipped root with its reason after every scan, plus a container-path hint.
- G-18-2: rows of managed stacks keep their live Migrate/Adopt buttons. Disable them, show "Already managed" and link to the stack.

Purpose: Docker Desktop users who type a host path see "Not found inside the Docktor container" and the /host hint instead of a silently missing stack; nobody can import a stack twice from the UI.
Output: two section components extracted from `brownfield-import.tsx` (CLAUDE.md page-composition rule; the file is near 300 lines), unit tests and Playwright updates.
</objective>
