<objective>
Turn the migration dialog's review step into a readable, real line diff. Per D-04 the client renders the `UnifiedDiff` that plan 18-02's preview endpoint now returns with the existing `UnifiedDiffView` (no second renderer: the side-by-side migration viewer and the local text-diff parser are deleted). Per D-05 the extracted `.env` preview is a read-only `CodeEditor` with secret values masked behind a reveal toggle, using a masking helper extracted from `diff-confirm-dialog.tsx` into `client/src/lib/env-mask.ts` (planner-chosen name; both dialogs share it). Per D-06 the dialog is widened with an `sm:`-prefixed class (the primitive's `sm:max-w-lg` beat the old unprefixed width, which is why the dialog never grew, #72) and restructured so header and footer stay pinned and the body scrolls at phone width.

Purpose: users can actually read what the migration will change before confirming.
Output: `migration-review-step.tsx`, `env-mask.ts`, updated wizard shell, deleted side-by-side viewer, component tests, Playwright mocks on the new response shape. The four-step flow, step indicator and steps 3-4 are plan 18-05; in this plan step 2 keeps its current footer (Back, Confirm & Migrate).
</objective>
