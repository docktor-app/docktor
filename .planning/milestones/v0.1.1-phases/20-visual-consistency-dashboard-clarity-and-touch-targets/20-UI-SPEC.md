### Font token (UI-03, D-05)

In `client/src/index.css`:

1. Add `@import "@fontsource-variable/geist-mono";` as the first statement of the file (CSS `@import` order), above `@import "tailwindcss";`.
2. Add inside the existing `@theme inline { ... }` block:

```css
--font-mono: "Geist Mono Variable", ui-monospace, SFMono-Regular, Menlo, Consolas, monospace;
```

Tailwind 4 then resolves the `font-mono` utility to this token, so **every existing `font-mono` call site switches to Geist Mono automatically** (about 20: log terminal, unified diff view, 2FA inputs, recovery codes, setup key, backup config summary, template repo URL, backup repository fields, cert/proxy error `<pre>` blocks, scan-skipped directories, env warnings). This is intended: one monospace family everywhere. The CodeMirror editors (`CodeEditor`/`ComposeEditor`) keep their own font configuration and are not touched.

Verification: a Playwright check (and manual network-tab check) that loading `/` makes **zero requests** to `fonts.googleapis.com`, `fonts.gstatic.com` or any other third-party host, and that the Geist Mono `.woff2` is served from the app origin. Weights used with Geist Mono are 400 and 600 only (the variable font covers both; no extra files).

## Spacing Scale

Declared values (multiples of 4), taken from the existing Tailwind scale:

| Token | Value | Usage in this phase |
|-------|-------|---------------------|
| xs | 4px | Tab bar wrapper padding (`py-1`/`px-1`) that contains the focus ring; gap between pagination buttons (`gap-1`) |
| sm | 8px | Label to input (`FormItem gap-2`); actions-row gap (`gap-2`); `FormActions` top padding (`pt-2`) |
| md | 16px | Field to field (`FormStack gap-4`); gap between table frame and pagination (`space-y-4`); stat card grid gap (`gap-4`) |
| lg | 24px | Last field to actions row (`gap-4` + `pt-2`); page content padding (`p-6`, existing) |
| xl | 32px | Compact icon-button size at `md`+ for pagination (`md:size-8`) and select trigger (`md:h-8`) |
| 2xl | 48px | Not used |
| 3xl | 64px | Not used |

Exceptions:
- **44px touch targets** (`size-11`, `h-11`) below `md` for the controls in the A11Y-01 list. 44 is not on the 4-point scale but is the WCAG 2.5.5 / Apple minimum and matches Phase 19 D-11. 36px (`md:size-9`) is the existing compact `Button size="icon"` size, kept as is.
- `gap-1.5` (6px) between the status dot and its label in `stack-status-badge.tsx`, `service-status-badge.tsx` (also `log-connection-status.tsx`): the only off-scale value kept, justified as the optical gap for an 8px dot beside 12px text (4px reads cramped, 8px detaches the dot). Out of scope to change; the executor edits only the label logic in those files and leaves the class as is.
- Inherited from shadcn, not re-specified: `px-2 py-1` on tab triggers.

### 1. Status casing (UI-02)

- One module owns formatting and presentation: `lib/status-labels.ts` exports `formatStatusLabel` and the two maps' shared helper; `getStackStatusPresentation(status)` and `getServiceStatusPresentation(containerState, healthStatus)` keep their signatures and return shapes (`label`, `tone`, `dotPulse`, plus `badgePulse` for stacks).
- Tone, pulse and dot behaviour are unchanged. Only `label` changes: stack labels go from Title Case to lowercase; service labels stay as they are.

### 5. Stack tab bar (UI-04)


- No scrollbar of either orientation is visible at desktop (>= 1280px), tablet (768px) and phone (375px) widths.
